# Goal (MVP)

Build a simple expense tracker with these features:

## Core Features

- [ ] Expense entry form (amount, description, category, date)
- [ ] List view of all expenses
- [ ] Delete expenses
- [ ] Category filtering (show all / filter by category)
- [ ] Total amount display
- [ ] Simple pie or bar chart showing spending by category
- [ ] Data persists in localStorage (survives page refresh)

## Categories

Use these default categories:
- Food & Dining
- Transport
- Shopping
- Entertainment
- Bills & Utilities
- Other

## Design Direction

- Clean, minimal interface
- Dark or light mode (your choice)
- Mobile-friendly layout
- Use Tailwind's default fonts (no custom fonts needed)
