# Cursor from Zero Starter Kit

Documentation files for the expense tracker workshop.

## Quick Start

1. Unzip this folder
2. Open it in Cursor
3. Rename `cursorignore.txt` to `.cursorignore`
4. Read the files to understand the project
5. Start building with the prompt below

## First Prompt

Copy this into Cursor to get started:

```
Read @OVERVIEW.md @GOAL.md @ARCHITECTURE.md and create a new Next.js project with the expense tracker structure. Set up:
1. The file structure from ARCHITECTURE.md
2. The Expense type
3. A basic Zustand store
4. A simple page that shows "Expense Tracker" as a heading
```

## Included Files

| File | Purpose |
|------|---------|
| `OVERVIEW.md` | What we're building and why |
| `GOAL.md` | MVP features and design direction |
| `ARCHITECTURE.md` | Tech stack and file structure |
| `JOURNAL.md` | Task checklist to track progress |
| `RULES.md` | Guidelines for Cursor |
| `cursorignore.txt` | Rename to `.cursorignore` |

## Tips

- Reference files with `@GOAL.md` in your prompts
- Update JOURNAL.md as you complete tasks
- If stuck, ask Cursor to explain the error
