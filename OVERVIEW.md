# Overview

A personal expense tracker web app that helps users log daily spending, categorize expenses, and visualize where their money goes.

## Problem

Tracking expenses is tedious. Most apps are bloated with features nobody uses. People just want to quickly log "50 THB for lunch" and see a summary at the end of the month.

## Target User

- Individuals tracking personal spending
- People who want simplicity over features
- Users comfortable with a web browser

## Why This Project?

Perfect for learning Cursor because it has:
- Forms (user input)
- Lists (displaying data)
- State management (adding/deleting)
- Charts (visual output)
- Persistence (localStorage)
