# Rules

## Code Style
- TypeScript with strict mode
- Functional components only
- Use async/await over .then()

## Patterns
- Zustand for all state management
- Tailwind CSS for styling (no CSS files)
- Small, focused components

## Naming
- Components: PascalCase (ExpenseForm.tsx)
- Functions: camelCase (handleSubmit)
- Types: PascalCase (Expense)

## Avoid
- Class components
- Inline styles
- Installing extra libraries unless necessary
- Over-complicated solutions

## When Stuck
- Start simple, add complexity later
- Ask Cursor to explain the error
- Check the browser console for errors
